# claude-skills

Skills for [Claude Code](https://code.claude.com/docs) from Reimagined Industries.

| Folder | What it is |
| --- | --- |
| [`ri-skills/`](ri-skills/README.md) | The ri SDLC: skills and review agents that take work from idea to merged code, with ceremony set per repo by risk |
| [`orion/`](orion/README.md) | Research skills that turn experimental evidence into a published paper |
| [`sdlc/`](sdlc/) | This repo's own SDLC records: the epics, stories, decisions and open questions behind these skills. A working example of ri-skills in use |

## Install

- **ri-skills:** copy the files into `~/.claude`, or install the plugin. See [installation](ri-skills/docs/installation.md).
- **orion:** copy the skill folders into `~/.claude/skills/`.
